🤖 AI Chatbot

A responsive AI-powered chatbot developed as an academic/personal project to explore Generative AI, Large Language Models (LLMs), conversational workflows, and backend API integration.

📌 Project Overview

The AI Chatbot provides a conversational interface through which users can interact with an AI model and receive responses to their queries. The project focuses on building a structured and responsive chatbot application using modern Generative AI technologies.

🛠️ Technologies Used

- Python
- LangChain
- LangGraph
- Groq
- Flask
- Pydantic

✨ Key Features

- Conversational interaction with an AI model
- Structured management of chatbot workflow
- LLM integration using Groq
- Backend API integration using Flask
- Request and response validation using Pydantic
- Modular conversational workflow using LangGraph
